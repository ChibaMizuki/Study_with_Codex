# Media Player

PySide6の日本語UI、VLCのメディア再生、yt-dlpのダウンロードを組み合わせたWindows用ポータブルアプリです。元アプリの連番画像関連の機能は含みません。

## 起動

`dist/MediaPlayer/MediaPlayer.exe` をダブルクリックしてください。Python・VLC・FFmpeg・Denoを別途インストールする必要はありません。`launch.bat` からも起動できます。

配布・移動する場合は **`dist/MediaPlayer` フォルダ全体** をコピーしてください。EXEだけでは動きません。インストーラー、ショートカット作成、OSへの登録は行いません。書き込み可能なフォルダに置いてください。

## 再生

- 「ファイルを開く」で動画・音声を再生します。ファイルを画面にドラッグするとプレイリストへ追加して再生します。
- 再生／一時停止、停止、シーク、音量、ミュート、全画面に対応します。
- 画面右上の「プレイリストを隠す／表示」またはCtrl+Pでプレイリストを切り替えます。非表示にすると動画が横へ広がります。リストの内容・再生は維持され、表示状態は次回起動にも引き継ぎます。
- 「全画面」またはF11で動画だけを画面いっぱいに表示します。メニュー、プレイリスト、操作ボタンを隠し、再生を継続します。EscまたはF11で元の画面へ戻ります。全画面中もSpace・矢印キー・M等で操作できます。
- プレイリストは複数ファイルの追加、選択して削除、新規作成、ドラッグでの並べ替え、枠外へドラッグで削除に対応します。
- リストをダブルクリック、または「リストを再生」でプレイリスト再生になります。前／次のボタンと自動連続再生が使えます。
- 「ループ」は初期状態でONです。単体再生では同じファイルを繰り返し、プレイリストでは最後から先頭へ戻ります。OFFでは最後で停止します。
- シャッフルの切り替え時には再生中のファイルを維持します。
- CSVは旧アプリと同じ1行1ファイルの形式です。旧CSVの絶対パスを読み込めます。存在しないファイルは件数を知らせてスキップします。
- CSV保存時は相対パスを使います。アプリ内のメディアとプレイリストを一緒に移動すれば、移動後も読み込めます。外部ファイルを移動した場合はリストを作り直してください。
- プレイリスト、音量、ループ、完了後の再生設定は終了時に保存します。次回起動時は自動再生しません。

## ダウンロード

1. 「ダウンロード」を開き、HTTP／HTTPSの動画URLを入力します。
2. 必要ならアプリ内の保存先フォルダを選びます。
3. 「完了後に再生する」を指定し、「ダウンロード開始」を押します。

最高品質の映像と音声を取得して、必要なら同梱FFmpegで結合します。結合後の実際のファイルをプレイリストへ追加します。複数動画を含むURLは、チェックを入れると全体を保存します。チェックを外した場合はyt-dlpの単体優先動作を使います。プレイリストのみのURLでは複数件になる場合があります。

転送量・速度・残り時間とログを表示します。サイズ不明の場合は進捗バーを待機表示にします。完成ファイルはダブルクリックで再生できます。複数件の一部が失敗した場合も、完成した分はリストに残ります。

キャンセルは通信の切り替わりや進捗通知時に反映されます。ファイル結合中・通信待機中は終了まで時間がかかります。ダウンロード中にアプリを閉じた場合も、キャンセルして安全に終了するまで画面を保持します。途中の `.part` ファイルは再開用に残します。

サイト側の仕様変更・認証・利用制限によって取得できない場合があります。ブラウザCookieの取り込みやログイン操作は旧アプリ同様に実装していません。YouTubeの認証付きコンテンツや会員限定動画の取得は保証しません。

## 保存場所

すべてアプリのフォルダ内です。ソース実行時はこのREADMEのあるフォルダ、EXE実行時はEXEのある `dist/MediaPlayer` が基準になります。

| フォルダ | 内容 |
| --- | --- |
| `downloads/` | ダウンロードファイル・再開用ファイル |
| `playlists/` | CSVプレイリストの標準保存先 |
| `data/settings.json` | 設定と前回のプレイリスト |
| `data/cache/` | yt-dlp・Denoのキャッシュ |
| `data/temp/` | 一時ファイル |
| `_internal/` | EXEの同梱ライブラリ・ツール |
| `licenses/` | 依存ライブラリのライセンス・出典 |

既存メディアとCSVはアプリ外から読み込めます。ダウンロードとCSVの書き込み先はアプリ内に限定しています。AppDataやユーザーのDownloadsへアプリのデータを保存しません。開発用uvの一時キャッシュは例外です。

## キーボード

| キー | 操作 |
| --- | --- |
| Space | 再生／一時停止 |
| ← / → | 5秒戻る／進む |
| Ctrl+← / Ctrl+→ | 前／次のメディア |
| M | ミュート |
| F11 / Esc | 動画だけを全画面表示／解除 |
| Ctrl+P | プレイリストの表示／非表示 |
| Ctrl+O | ファイルを開く |
| Ctrl+Shift+O | リストへ追加 |
| Ctrl+L / Ctrl+S | CSV読込／保存 |
| Ctrl+D | ダウンロード画面 |

文字入力欄の編集中は文字入力を優先します。

## 開発・再ビルド

このフォルダをカレントディレクトリにして実行します。親プロジェクトの環境から独立した `pyproject.toml`、`uv.lock`、`.venv` を使用します。

```powershell
uv sync
uv run python main.py
uv run pytest
uv run python build.py
```

ローカルの `tools/` にVLCのDLLとplugins、FFmpeg／ffprobe、Denoを用意済みです。再ビルドはこのコピーを使います。元アプリへのアクセスは不要です。依存追加は `uv add`、開発依存は `uv add --dev` を使います。yt-dlpを更新する場合は `uv lock --upgrade-package yt-dlp --upgrade-package yt-dlp-ejs`、`uv sync`、テスト、再ビルドを実行してください。

EXE更新時は `build/portable/` でビルドしてから配布フォルダへアプリを上書きします。`dist/MediaPlayer` 全体を削除しないため、ダウンロード済みメディアや設定、CSVは残ります。更新前にアプリを終了してください。

### GitHubから取得した場合

Gitにはソース・依存定義・ライセンスを保存します。大容量の `tools/`、`dist/`、開発環境、利用者の動画・設定はGitに含めません。GitHubからソースを取得した場合、実行・ビルドの前にWindows x64向けのツールを次の配置で用意してください。システムへインストールする必要はありません。

```text
tools/
  ffmpeg.exe
  ffprobe.exe
  deno.exe
  vlc/
    libvlc.dll
    libvlccore.dll
    plugins/
```

VLCは公式のポータブル配布物からDLLとpluginsを取り出し、その他に同梱DLLがある場合は同じフォルダへ配置します。FFmpegとDenoはWindows x64の配布物を展開します。現在の同梱バージョンは `licenses/NATIVE-VERSIONS.txt` に記録しています。ツールの出典は末尾のリンクと `licenses/THIRD-PARTY.md` を参照してください。

## 経過ログの実装

yt-dlpをPythonライブラリとして呼び出し、`YoutubeDL` のオプションに `logger` を指定しています。`downloader.py` の `DownloadWorker` 自身がloggerとなり、`debug()`・`warning()`・`error()`で文字列を受け取ります。通常の情報ログも `debug()` に渡されるため、`[debug]` で始まる詳細ログだけを除外しています。

受け取った文字列はQtの `Signal(str)` で送信します。`app.py` で次の接続を行い、GUI側の `QPlainTextEdit` に追記しています。

```python
worker.message.connect(self.log.appendPlainText)
```

ダウンロードは `QThread` で実行し、QtのSignal経由でGUIスレッドへ渡すことで、画面を固めずにログを表示します。コンソールの出力を読み取っているわけではありません。ログ欄は最大500ブロックを保持し、新しいダウンロードを始めると消去します。

進捗バーと転送量・速度・残り時間は、文字列ログとは別に `progress_hooks` の辞書データから計算しています。

## 使用ライブラリ

- [PySide6](https://doc.qt.io/qtforpython-6/): UI
- [VLC / libVLC](https://www.videolan.org/vlc/libvlc.html): 再生
- [yt-dlp](https://github.com/yt-dlp/yt-dlp): ダウンロード
- [yt-dlp EJS](https://github.com/yt-dlp/yt-dlp/wiki/EJS) / [Deno](https://deno.com/): YouTubeのJavaScript処理
- [FFmpeg](https://ffmpeg.org/): 映像と音声の結合
- [PyInstaller](https://pyinstaller.org/): ポータブルEXE作成
