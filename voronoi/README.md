# ボロノイ分割

実装を始める際は [コード面の実装ガイド](IMPLEMENTATION.md) を併せて読んでください。
引数・戻り値の形、小さな入出力例、配列の読み方、用意済みコードの役割を説明しています。

## 定義と前提

母点（site）p_iに対し、「p_iが最も近い点である場所」を集めた領域がボロノイ領域です。
この教材では2次元、通常のユークリッド距離、重みなしを扱います。

`V_i = {x | ||x - p_i||² <= ||x - p_j||² （全てのj）}`

2点から等距離の場所は垂直二等分線です。領域は凸で、外側の領域は無限に広がります。
半平面教材では `[0,1] × [0,1]` の矩形内に切り取ります。
格子教材も同じ範囲を描画します。SciPyは無限領域も計算し、表示範囲のみ制限します。
境界上は複数領域が共有しますが、格子の番号付けは小さい母点番号を優先します。

## 手法の比較

nは母点数、Gは格子点数です。以下の計算量は2次元についてのものです。

| 手法 | 基本的な考え方 | 時間の目安 | この教材 |
|---|---|---|---|
| 格子の総当たり | 各格子点から全母点への距離を比較 | O(Gn) | 自作する課題1 |
| 半平面の逐次交差 | 垂直二等分線で領域を切り取る | この素朴な実装は最悪O(n³) | 自作する課題2 |
| SciPy / Qhull | 既存ライブラリに計算を任せる | 入力・実装に依存 | API利用の課題3 |
| Fortune法 | 走査線と放物線の境界を更新 | O(n log n) | 解説のみ |
| 分割統治法 | 左右の図を作り境界を併合 | O(n log n) | 解説のみ |
| ドロネー分割の双対 | 三角形の外心を結ぶ | 分割構築後の変換O(n) | 解説のみ |

## 1. 格子点での総当たり

ファイル: `voronoi_brute_force.py` / `voronoi_brute_force_solution.py`

1. 表示領域に格子点を並べます（準備済み）。
2. 各格子点で全母点への平方距離 `(x-px)² + (y-py)²` を調べます。
3. 最小距離を持つ母点の番号を記録し、その番号で色を塗ります。

平方根を取っても距離の大小は変わらないので不要です。
解答は母点を1つずつ処理し、最小距離と番号の配列を更新します。
時間O(Gn)、追加メモリO(G)。これは格子でサンプリングした図であり、
境界の正確な線分や頂点は出力しません。解像度を2倍にするとGは約4倍になります。

学習ポイント: 二重ループで考えてからNumPy配列で格子全体を計算する。
`<` を `<=` に変えたとき、等距離点の番号がどう変わるか観察してください。

## 2. 半平面の交差

ファイル: `voronoi_half_plane.py` / `voronoi_half_plane_solution.py`

領域の定義を展開すると、二次の項が消えます。

```text
||x-p||² <= ||x-q||²
2(q-p)・x <= ||q||² - ||p||²
(q-p)・x <= (q-p)・(p+q)/2
```

右の不等式は1つの半平面です。母点pの領域は全てのqに対する半平面の共通部分です。
最初に矩形を置き、それを1つずつ切り取ります。

凸多角形の各辺s→eについて、`d(v) = normal・v - offset` で内外を判断します。

- 内→内: eを追加。
- 内→外: 境界との交点だけ追加。
- 外→内: 交点とeを追加。
- 外→外: 何も追加しない。

境界を横切るとき、交点は `s + t(e-s)`、`t = d(s)/(d(s)-d(e))` です。
これはSutherland–Hodgman型のクリッピングです。
各切り取りが最大O(n)頂点を走査し、各母点につきO(n)回、母点はn個なので最悪O(n³)。
この実装の出力を含むメモリの保守的な上界はO(n²)です。
高度な半平面交差法とは計算量を区別してください。

1点、2点、共線の母点も扱えます。重複点は領域の所有が曖昧になるため入力時に拒否します。
浮動小数点による丸め誤差があるので数学的な厳密演算ではありません。
この教材のような0〜1付近の座標向けです。極端な座標やほぼ重複した点では
正規化や頑健な幾何述語が必要になります。

## 3. SciPy / Qhull

ファイル: `voronoi_scipy.py` / `voronoi_scipy_solution.py`

これは既存実装を使い、結果のデータ構造を理解する課題です。
`scipy.spatial.Voronoi(points)` は内部でQhullを使用します。
`vertices` は頂点座標、`ridge_points` は境界を挟む母点の組、
`ridge_vertices` は境界の頂点番号です。母点iの領域は
`regions[point_region[i]]` で参照します。
`-1` は無限遠を表す印なので通常の頂点添字として参照しないでください。
共線などの退化した入力はQhullErrorになることがあります。
API詳細: [SciPy公式](https://docs.scipy.org/doc/scipy/reference/generated/scipy.spatial.Voronoi.html)。

## 発展: Fortune法（走査線）

平面を走査線で順に通過し、既に見た母点と走査線から等距離の放物線でできる
「ビーチライン」を管理します。母点に達するsite eventでは弧を追加し、
弧が消えるcircle eventではボロノイ頂点を確定します。
ビーチラインを平衡木、イベントを優先度付きキューで管理すればO(n log n)、空間O(n)。
無効になったcircle eventの削除、同時イベント、共線・共円配置への対処が難所です。
最初の実装課題にはせず、木とヒープを学んでから取り組むのがおすすめです。

## 発展: 分割統治法

母点をx座標でソートして左右に分け、小さな図を再帰的に作成します。
左右の母点集合から等距離となる境界を追跡し、不要な辺を切って併合します。
ソート後の分割と線形時間の併合ができれば
`T(n) = 2T(n/2) + O(n)` からO(n log n)になります。
難所は境界の追跡と、辺・頂点・領域の隣接関係を矛盾なく更新することです。

## 発展: ドロネー三角形分割から変換

母点をドロネー三角形分割し、各三角形の外心を計算します。
隣接三角形の外心を結ぶとボロノイ辺になり、凸包上の辺には外向きの半直線が対応します。
2次元の分割サイズはO(n)なので変換はO(n)。全体はドロネー分割の構築法に依存します。
たとえばランダム化逐次挿入と効率的な点位置探索では期待O(n log n)ですが、
毎回全三角形を調べる素朴なBowyer–Watson実装は最悪O(n²)になります。
4点以上が共円の場合は三角形分割が一意でなく、同じ外心や長さ0の双対辺が生じます。
凸包・外接円・双対グラフを学ぶ題材として使えます。

発展手法の参考: [計算幾何の教科書（CMU公開PDF）](https://www.cs.cmu.edu/afs/cs/academic/class/15456-s13/Handouts/BKOS.pdf)。

## 実行と答え合わせ

ルートフォルダから実行してください。

```powershell
uv run python -m voronoi.voronoi_brute_force_solution --save outputs/brute_force.png
uv run python -m voronoi.voronoi_half_plane_solution --save outputs/half_plane.png
uv run python -m voronoi.voronoi_scipy_solution --save outputs/scipy.png
uv run pytest
```

同じ `--points` と `--seed` を指定すると同じ母点で比較できます。
格子法のみ `--resolution` が計算結果の解像度に影響します。
描画補助関数は `common.py` にあります。
テストは既定では解答を対象にします。学習後は `tests/test_voronoi.py` の
import先から `_solution` を外すと、自作した同じ関数を検証できます。
総当たりでは等距離時の番号、半平面では面積の合計と最近点条件、
SciPyでは既知の外心と退化入力を確認します。
